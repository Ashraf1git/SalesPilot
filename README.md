# SalesPilot

Business Sales and Inventory Management Platform.

## Features

- Product management (CRUD)
- Sales recording
- Automatic inventory updates
- Customer management
- Sales analytics
- Product search and category filtering
- Low-stock alerts
- REST API using FastAPI
- Interactive frontend using Streamlit

## Technology Stack

- Python
- FastAPI
- Streamlit
- Pydantic
- Pandas
- Plotly
- Requests
- Pytest

## Architecture

Streamlit Frontend → FastAPI Backend → In-memory Python Data Store
